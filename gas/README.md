# 予約フォーム ⇔ Googleカレンダー連携セットアップ

サイトの「オンラインでのご予約」フォームから送信された内容を、Googleカレンダーに自動登録する仕組みです。
GitHub Pages(静的サイト)からGoogleカレンダーへ直接書き込むことはできないため、間に **Google Apps Script(GAS)** を挟んでいます。

```
サイトの予約フォーム → (fetch送信) → Google Apps Script → Googleカレンダーに予約登録 + 確認メール送信
```

## 1. Apps Script プロジェクトを作成する

1. https://script.google.com を開く(予約を受けたいGoogleアカウントでログイン)
2. 「新しいプロジェクト」をクリック
3. デフォルトで開かれる `コード.gs` の中身を全て削除し、このフォルダの `Code.gs` の内容を丸ごと貼り付ける
4. 左上のプロジェクト名(「無題のプロジェクト」)を「Produce nail 予約」などに変更
5. `Code.gs` 内の `OWNER_EMAIL`(初期値は `your-email@gmail.com`)を、新規予約の通知を受け取りたいご自身のメールアドレスに変更(不要なら空文字 `''` に)

## 2. Webアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択(歯車アイコン)で「ウェブアプリ」を選択
3. 「実行するユーザー」→ **自分**
4. 「アクセスできるユーザー」→ **全員**
5. 「デプロイ」をクリック
6. 初回は権限の承認画面が出るので、自分のアカウントで許可する(「詳細」→「(プロジェクト名)に移動」→「許可」)
7. 発行された **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec` の形式)をコピーする

## 3. サイト側にURLを設定する

コピーしたURLを、Claudeに伝えてください。`index.html` 内の以下の1行に設定して、GitHubに反映します。

```javascript
var RESERVATION_ENDPOINT = ''; // ← ここにコピーしたURLを貼る
```

設定前は、フォーム送信時に「現在オンライン予約フォームは準備中です」と表示されるだけで、エラーにはなりません。

## 4. 動作確認

1. サイトの予約フォームから、実際に近い内容(自分の連絡先など)でテスト送信してみる
2. Googleカレンダーに予定が登録されるか確認
3. 入力したメールアドレスに確認メールが届くか確認
4. `OWNER_EMAIL` を設定していれば、そちらにも通知メールが届くか確認

## コードを変更したとき

`Code.gs` の内容を編集したら、再度反映するために **「デプロイ」→「デプロイを管理」→ 該当のデプロイの鉛筆アイコン → バージョン「新バージョン」→ デプロイ** が必要です(URLは変わりません)。

## 予約ルールについて

- 営業時間・定休日・メニューごとの所要時間は `Code.gs` 冒頭の定数で管理しています。サイトのMenuセクションの内容を変更した場合は、ここも合わせて更新してください。
- ダブルブッキング(同じ時間帯への重複予約)は自動でブロックされます。
